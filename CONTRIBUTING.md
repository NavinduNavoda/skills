# Contributing

Bug reports, ideas and pull requests are all welcome.

- **Found a bug or have an idea?** [Open an issue](https://github.com/NavinduNavoda/skills/issues/new/choose). Saying what you ran and what happened helps a lot.
- **Want to change something?** Open a pull request. For a big change, an issue first saves you work if I'd go another way.
- **Adding a skill?** [`AGENTS.md`](./AGENTS.md) explains how skills are named and laid out. Your agent reads it too.
- **Found a security problem?** Report it privately, as [`SECURITY.md`](./SECURITY.md) describes.

Be chill: see the [code of conduct](./CODE_OF_CONDUCT.md).
